# SSL Origin Studio

A native macOS signal-flow teaching simulator for the SSL Origin EVO console.

## Downloads

Installers will be available on the [Releases page](https://github.com/TxDigi/SSL-Origin-Studio/releases). The app can check this repository for published updates.

## Current beta

Version **0.3b** is under instructor review. It demonstrates routing and pass-through audio; EQ, filters and dynamics do not process the sound.

Requires macOS 26 or later on Apple Silicon. A 2560 × 1440 display is preferred; 1920 × 1080 is the minimum target.

This repository is the download and release location.
